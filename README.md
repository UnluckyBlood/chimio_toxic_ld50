# 🧪 Chemio Profiler (chimio_toxic_ld50)

Прогноз токсичности, LD50 (перорально и внутрибрюшинно), антибактериальной (ESKAPE) и противогрибковой активности по структуре молекулы (SMILES или InChI).

---

## 🚀 Установка в один клик (Windows)

Вам **не нужно** ничего устанавливать (Python, библиотеки и модели скачаются автоматически).

1. Нажмите зеленую кнопку `<> Code` вверху страницы и выберите `Download ZIP`.
2. Распакуйте скачанный архив в любую папку (например, на Рабочий стол).
3. Зайдите в папку и сделайте **двойной клик по файлу `install.bat`**.

⏳ **Что произойдет дальше?**
Откроется черное окно. Скрипт сам:
- Скачает встроенный Python 3.10.
- Установит все необходимые библиотеки (Streamlit, RDKit, PyTorch, ADMET-AI и др.).
- Скачает 1.2 ГБ моделей ESKAPE.
- Запустит локальный сервер и **откроет браузер** с готовым интерфейсом.

*Первый запуск занимает 5–15 минут (в зависимости от скорости интернета).*

## ⚡ Как запустить программу во второй раз
После того как установка завершится, вам больше не нужно запускать тяжелый `install.bat`.
Для мгновенного запуска просто делайте двойной клик по файлу **`launch.bat`**.
