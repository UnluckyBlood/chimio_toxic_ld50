# chimio_toxic_ld50

Прогноз токсичности, LD50 (oral/i.p.), антибактериальной (ESKAPE) и противогрибковой активности по структуре молекулы.

## Быстрый старт
1. `git clone https://github.com/UnluckyBlood/chimio_toxic_ld50.git`
2. `pip install -r requirements.txt`
3. `streamlit run streamlit_app.py`

*Примечание: папка `db/` с моделями ESKAPE (1.2 ГБ) не входит в репозиторий из-за ограничений GitHub. Её нужно скачать отдельно.*
