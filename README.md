# 🧪 Chemio Profiler (chimio_toxic_ld50)

Прогноз токсичности, LD50 (перорально и внутрибрюшинно), антибактериальной (ESKAPE) и противогрибковой активности по структуре молекулы (SMILES или InChI).

---

## 🚀 Установка в один клик (Windows)

Вам **не нужно** ничего устанавливать (Python, библиотеки и модели скачаются автоматически).

1. Нажмите зеленую кнопку **`<> Code`** вверху страницы и выберите **`Download ZIP`**.
2. Распакуйте скачанный архив в любую папку (например, на Рабочий стол).
3. Зайдите в папку и сделайте **двойной клик по файлу `install.bat`**.

⏳ **Что произойдет дальше?**
Откроется черное окно. Скрипт сам:
- Скачает встроенный Python 3.10.
- Установит все необходимые библиотеки (Streamlit, RDKit, PyTorch, ADMET-AI и др.).
- Скачает 1.2 ГБ моделей ESKAPE.
- Запустит локальный сервер и **откроет браузер** с готовым интерфейсом.

*Первый запуск занимает 5–15 минут (в зависимости от скорости интернета). В следующий раз просто запустите `install.bat` снова — он увидит, что всё уже скачано, и сразу откроет интерфейс.*

## 💻 Ручная установка (для разработчиков / Linux / macOS)

Если вы хотите запустить проект из исходников:

```bash
# 1. Клонировать репозиторий
git clone https://github.com/UnluckyBlood/chimio_toxic_ld50.git
cd chimio_toxic_ld50

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Скачать модели ESKAPE
git clone https://github.com/arnolp3/The-ESKAPE-Model.git eskape_repo
# Скопируйте папку eskape_repo/db в корень проекта (рядом с streamlit_app.py)

# 4. Запустить приложение
streamlit run streamlit_app.py
```

---
*Примечание: папка `db/` (1.2 ГБ) и локальное окружение `python/` не хранятся в репозитории из-за ограничений GitHub. Установщик `install.bat` скачивает их автоматически.*
